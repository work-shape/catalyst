# Security

## Report a vulnerability

Write to [hello@workshape.ai](mailto:hello@workshape.ai) with "Security" in the subject.

Please do not open a public issue for a vulnerability.

This covers the content of this repository, the `@work-shape/catalyst-*` packages on npm and the Workshape Catalyst platform itself. The platform's source is not public, so report a problem you find on an instance here as well.

Tell us:

- what is affected: the package and its version, or the instance address and its release;
- what an attacker could do, and the steps to reproduce it;
- whether you have told anyone else.

Do not include passwords, keys or customer data in the report. If you need one to show the problem, describe it and we ask for it in a safer way.

We confirm that we received your report and tell you when it is fixed.
